## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/nazifa-buildscodes/nazifa-portfolio.git
```

Go to the project directory:

```bash
cd nazifa-portfolio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

## 📦 Build

```bash
npm run build
```
